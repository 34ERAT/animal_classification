⚠️ Troubleshooting
If camera shows 0x106 (ESP_ERR_NOT_SUPPORTED):
1. Reseat the OV2640 ribbon cable (gold contacts face down).
2. Power via 5 V / ≥ 1 A — not from the FTDI 3.3 V pin.
3. Enable PSRAM in Arduino IDE → Tools → PSRAM → "Enabled".
4. Board must be set to AI Thinker ESP32-CAM.
Flash Command (esptool)
python -m esptool --chip esp32 --port /dev/ttyACM0 --baud 460800 write_flash -z 0x1000 firmware.bin

System Operating Mode
Choose the active behavior. You can also switch modes instantly at any time from the Run System tab without stopping the process!
🛡️ Guard Mode (Farm Defense)
Restricts turret targeting to the compact Farm Region. Only aims and fires at animals and bottles approaching or entering the farm boundary.
🎯 Bottle Tracking Mode (Full FOV)
Actively tracks and centers pan/tilt servos on bottles across the entire camera field of view. Firing is disabled for safe observation and smooth tracking.
Compact Farm Region (Guard Zone)
The farm region is now a compact zone (~25% of the frame) instead of half the screen. This allows the system to monitor approaching animals before they breach the farm boundary.

🚀 Quick Start
# 1. Flash the ESP32-CAM (after configuring WiFi in the ESP32-CAM tab above)
#    Open esp32cam/esp32cam.ino in Arduino IDE → Upload

# 2. Launch the tracking system (one command does everything)
python main.py

# 3. Optional flags
python main.py --source udp           # ESP32-CAM (default)
python main.py --source 0             # USB webcam index 0
python main.py --no-gui               # headless / SSH mode
python main.py --udp-port 5005        # override UDP port
